
# Smile Bags · Jigsaw Puzzles

OneWord jigsaw puzzles for the Smile Bags care packages.

## Naming convention

```
OneWord_##piece.ext
```

- **OneWord** — the word, first letter capitalized (`Filter`, `Anchor`, `Clear`)
- **##** — piece count, always two digits (`08`, `12`, `16`, `18`, `20`, `24`)
- **piece** — literal text
- **.ext** — the original file type, kept as exported (`.jpg`, `.png`, or `.pdf`)

Example → `Filter_24piece.jpg` is the Filter puzzle at 24 pieces.

The piece count is the Mind's Eye difficulty ladder: more pieces → older recipients.
