03 · Snap-Fit Design

Make Pieces That Click

OnShape's parametric tools make snap-fit design more precise than drag-and-drop editors. Use sketch constraints and dimensions to control clearance exactly.

⚡ The Golden Rule

Add 0.3–0.5mm of clearance between mating parts. In OnShape: dimension your tab at 5mm, dimension the slot at 5.3–5.5mm. Use the Offset Plane or Shell feature to maintain consistent wall thickness. Always print a test piece before printing the full kit.

Joint Type Best For OnShape Approach
Tab & Slot Fins, wings, panels Sketch a rectangular tab. Use an Extrude (Add) on one part. Use Extrude (Remove) + offset dimension on the mating part.
Pin & Socket Rotating joints, heads, wheels Sketch a circle for the pin. Extrude (Add). On mating part, use Extrude (Remove) with diameter + 0.4mm for the socket.
Press-Fit Tube Axles, pegs, masts Extrude a cylinder peg. Use Hole feature on the socket part — set hole diameter 0.3mm smaller than peg for friction fit.
Cantilever Clip Covers, lids, deck plates Sketch a thin arm profile with a hook at the end. Extrude thin (1.5–2mm). Use Shell to control wall thickness uniformly.
04 · Process

Step-by-Step in OnShape

Follow these eight steps from concept to printed kit.

1
Choose Your Model & Plan Your Part Studios
Pick one model from the library. In OnShape, each part will live in its own Part Studio — plan one Part Studio per piece. Sketch all pieces on paper first — label each part and mark connection points. Decide which joint type you will use for each connection before opening OnShape.
2
Create a New OnShape Document
Go to onshape.com and create a new document. Name it: [Last Name] — [Model Name] Kit. Create a Part Studio for your largest/main piece first. Use the Rename option to label each Part Studio clearly (e.g. 'Body', 'Wing Left').
3
Build Each Piece with Parametric Sketches
Start each part with a fully constrained sketch — all lines black, no blue (underconstrained) lines. Use the Dimension tool to set all sizes precisely. Apply geometric constraints (horizontal, vertical, parallel, tangent) as needed. Extrude, revolve, or loft from your sketch. Use the Mirror feature for symmetric parts — wings, legs, fins, wheels.
4
Add Snap-Fit Connections
On the connecting piece: sketch and extrude your tab, pin, or peg (Add). On the receiving piece: sketch and extrude a slightly larger slot or socket (Remove). Use the Dimension tool to set clearance precisely — tab + 0.4mm = slot. Keep all snap features at least 3mm thick for clean printing. Use the Measure tool in OnShape to verify your clearance before exporting.
5
Assemble in the Assembly Tab
Create a new Assembly tab in your document. Insert all Part Studio parts into the Assembly. Use Fastened mates for fixed connections, Revolute mates for rotating joints. Check that all pieces fit together visually. Use the Interference Detection tool to catch overlapping geometry.
6
Test Your Tolerances
Export just one connection pair as STL — one tab piece and one slot piece. Right-click the part in the Parts list → Export → STL → Fine resolution. Print the test pieces and try snapping them together. Too tight: increase slot dimension by 0.2mm and re-export. Too loose: decrease slot dimension by 0.2mm. Once the fit is right, apply the same clearance to all other connections.
7
Add the Optional OneWord
Create a new sketch on a visible face of your chosen part. Use the Text tool in OnShape's sketch environment. Set text height to 8–10mm. Set extrude depth to 1mm (Add) for raised text. Position where the child will see it when the kit is assembled. This step is optional — your kit is complete without it.
8
Export STL Files & Submit
For each part: right-click in the Parts list → Export → STL → Fine resolution. Name each file: [LastName]_[ModelName]_[PartName].stl. Share your OnShape document: Share → Anyone with the link → Can view. Submit your share link via the Smile Bags submission form. Upload your STL files to the class Google Drive folder.
