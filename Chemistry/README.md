## The concept — 25 words, 25 elements, one story

Every OneWord is paired with a real element whose chemistry mirrors the meaning of the word. No forced fits — each pairing has a real chemical reason.

| OneWord | Element | Connection |
|---|---|---|
| ABSORB | C · Carbon | Activated carbon absorbs toxins by trapping them in its porous structure |
| ADAPT | Hg · Mercury | The only metal liquid at room temperature — adapts to any container |
| ANCHOR | Fe · Iron | Iron's density made it the anchor of choice for thousands of years |
| BALANCE | Mg · Magnesium | Balances electrolytes in muscles and nerves |
| BLOOM | P · Phosphorus | Fuels the energy plants need to flower |
| BREATHE | O · Oxygen | Every breath is 21% oxygen |
| CLEAR | He · Helium | No color, no smell, no taste — pure clarity |
| CONNECT | Si · Silicon | Silicon chips connect everything in the modern world |
| CYCLE | N · Nitrogen | 78% of every breath — nitrogen cycles through air, soil, life |
| EMERGE | Ti · Titanium | Emerged in 1791 as the strength-to-weight champion |
| FILTER | Ag · Silver | Silver ions kill bacteria — used in water filters for centuries |
| FLOW | H · Hydrogen | The lightest element — flows through every river as part of water |
| GROW | K · Potassium | The K in NPK fertilizer — essential for plant growth |
| HEAL | Zn · Zinc | Speeds wound healing and supports immune cells |
| MIGRATE | Na · Sodium | Sodium ions migrate across cell membranes to send signals |
| PERSIST | W · Tungsten | Highest melting point of any metal — persistence at 3,422°C |
| RENEW | Li · Lithium | Lithium batteries renew themselves through thousands of charge cycles |
| RESTORE | Ca · Calcium | 99% of body calcium restores and rebuilds bone |
| RETURN | Cu · Copper | Returns to its conductive form even after a thousand uses |
| RISE | Ne · Neon | Lighter than air — rises and glows red when electrified |
| ROOT | B · Boron | Strengthens plant cell walls — without it, roots can't form |
| SHINE | Au · Gold | Gold never tarnishes — its shine lasts forever |
| SUSTAIN | S · Sulfur | Holds proteins together — the bonds that sustain life |
| THRIVE | I · Iodine | The thyroid needs iodine to thrive — controls every cell's energy |
| TRANSFORM | Pt · Platinum | Platinum catalysts transform pollutants into harmless gases |

## Category color coding

Each OneWord-element pair belongs to one of five thematic families. Tile color in the interactive and print versions reflects the category.

- 🌱 **Growth** (green) — BLOOM, EMERGE, GROW, RENEW, ROOT, THRIVE
- 🌊 **Change · Flow** (blue) — ADAPT, CYCLE, FLOW, MIGRATE, RETURN, TRANSFORM
- ⚓ **Strength** (amber) — ANCHOR, PERSIST, RESTORE, RISE, SUSTAIN
- 🧘 **Inner · Balance** (teal) — ABSORB, BALANCE, BREATHE, CLEAR, HEAL
- ✨ **Light · Connect** (coral) — CONNECT, FILTER, SHINE

## Standards alignment

Virginia Chemistry SOLs supported by this resource:

- **CH.3** — Chemical bonding and molecular structure
- **CH.5** — Solutions, solubility, mixtures (FILTER, FLOW, CLEAR, ABSORB)
- **CH.6** — Chemical reactions and energy (TRANSFORM, CYCLE, RENEW)

## Brand & repo conventions

This is the **first class folder** in the `kellamsmilebags` repo. It sets the precedent for the post-Expo folder migration:

- **Folder name:** Capitalized class name, no spaces (`Chemistry`, not `chemistry` — GitHub Pages is case-sensitive, Standard #14)
- **File naming:** Existing `Smile Bags_*` prefix convention preserved inside the folder for now
- **README.md required** in every class folder — set context for future-Laura
- **Internal links** from `index.html` point to `Chemistry/filename.html` (relative path from repo root)
