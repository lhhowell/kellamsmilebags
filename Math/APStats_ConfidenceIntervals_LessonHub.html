Why This Lesson Works
From Plug-and-Chug to Genuine Understanding
A 60-minute lab that uses AI to make the most-misunderstood concept in AP Statistics visible.

The "95%" in a 95% confidence interval is the single most misinterpreted phrase in AP Statistics. Students plug numbers into the formula correctly, then describe the interval as containing the parameter "with 95% probability." Year after year, this misconception sinks otherwise strong inference responses on the AP exam.

This lesson treats the misconception head-on by making confidence visible. Students don't just compute one interval — they watch 100 intervals appear at once on a graph, color-coded by which ones capture the true parameter and which ones miss. The abstract phrase "95% of intervals will capture the true value" becomes the literal coverage rate at the top of the chart.

The Five Ways to Integrate AI Here

This lesson implements Way #2 (Simulation Coder) as its core. The other four are listed below as available variations or extensions. The PBA at the end of this Hub combines several.

Skeptical Auditor

Way 2 · This Lab

Way 3 · Context
Context Generator
AI generates three plausible real-world scenarios for the same numbers. Defect rate vs. mortality rate carries different stakes.
Way 4 · Bust
Misconception Buster
AI predictably produces a wrong CI interpretation. Students catch it and rewrite using correct AP language.
Way 5 · Refiner
Wording Refiner
Students draft their CI conclusion, AI checks for AP-required precision (population? context? probability vs. confidence?).

What This Lesson Does (and Doesn't) Replace

This lab does not replace the formula derivation or condition-checking work that happens before students get here. It assumes students can already calculate a one-proportion z-interval. What it replaces is the moment in a traditional lecture where the teacher tries to explain what "95% confident" means with words alone. The simulation lets students see it.

The pedagogical move Students who watched the simulation will rarely write "there is a 95% probability the true proportion is in this interval" again. Once you've watched five red intervals appear next to the true value line, you understand viscerally that some intervals just miss — and that the 95% refers to the method, not any single interval.

The Data: x = 107, n = 1560

The default values give p̂ ≈ 0.0686, a small proportion. This is deliberate: small proportions challenge the Large Counts Condition and produce visibly narrow intervals. You can later switch to p = 0.50 (Question 7) to demonstrate the worst-case margin of error — the symmetry is striking.

Why 60 Minutes

A traditional version of this content typically takes 90+ minutes split across two lessons (concept day + practice day). The AI-integrated version compresses both because the simulation handles the visualization work that would otherwise require board diagrams and verbal explanation. Students iterate parameters in seconds and see the effects immediately.

Step 1 · Open Gemini and paste this message

Initial Message
"Please run the following Python simulation for me. After you run it, I will ask you to change some of the parameters (like confidence level or sample size) and re-run it."

Step 2 · Paste the Python code that follows

Python · Simulation Code
import numpy as np import matplotlib.pyplot as plt import matplotlib.patches as mpatches from scipy.stats import norm def run_ci_simulation(true_p=107/1560, n=1560, num_sims=100, conf_level=0.95): z_star = norm.ppf(1 - (1 - conf_level) / 2) np.random.seed() successes = np.random.binomial(n=n, p=true_p, size=num_sims) p_hats = successes / n margins = z_star * np.sqrt(p_hats * (1 - p_hats) / n) lower, upper = p_hats - margins, p_hats + margins captures = (lower <= true_p) & (upper >= true_p) num_captured = captures.sum() fig, ax = plt.subplots(figsize=(10, 6)) for i in range(num_sims): color = "#2E86AB" if captures[i] else "#E84855" ax.plot([lower[i], upper[i]], [i, i], color=color, linewidth=1.4, alpha=0.85) ax.plot(p_hats[i], i, "o", color=color, markersize=2.5) ax.axvline(true_p, color="black", linewidth=1.8, linestyle="--", label=f"True p = {true_p:.4f}") ax.set_title(f"{conf_level*100:.0f}% Confidence Intervals ({num_sims} Samples, n={n})\nActual Coverage: {num_captured/num_sims*100:.1f}%", fontweight="bold") ax.set_yticks([]) ax.set_xlim(true_p - (margins.mean()*2.5), true_p + (margins.mean()*2.5)) plt.show() run_ci_simulation()

Step 3 · Confirm the first graph appears

Gemini will run the code and produce a graph showing 100 confidence intervals. You should see mostly blue intervals (which captured the true proportion) with a few red intervals mixed in (which missed). A dashed black vertical line marks the true value p = 107/1560 ≈ 0.0686.

Grading Criteria · 12 Points Total
Lab Rubric
Four conceptual domains drawn from the ten questions. Each domain graded on a 3-point scale.
Domain Developing · 1 pt Proficient · 2 pts Exemplary · 3 pts
Coverage & Method Qs 1, 6, 8 Describes the coverage rate as the percent of intervals shown, without connecting it to method reliability. Explains that the coverage rate measures how often the method captures the true value, and that red intervals are method misses (not math errors). Connects coverage to the Law of Large Numbers: as the number of simulations grows, the empirical coverage converges to the stated confidence level. Names red intervals as inevitable outcomes of correct procedure.
Confidence Level Effects Qs 2, 3 Notices that higher confidence makes intervals wider, but cannot explain the cause. Connects wider intervals to a larger z* critical value. Identifies the trade-off: precision vs. reliability. Articulates the full trade-off explicitly: confidence and precision pull against each other. References that z* = 1.96 for 95% becomes 2.576 for 99%, multiplying the standard error and widening the margin.
Sample Size & SE Qs 4, 5, 10 Notes that smaller samples produce wider intervals but doesn't use the SE formula. Uses the formula SE = √(p̂(1−p̂)/n) to show that n in the denominator causes SE (and margin of error) to shrink as n grows. Resolves Q10 (the precision-confidence paradox) cleanly: the only way to get both higher confidence and narrower intervals is to increase the sample size. Recognizes n is the lever that doesn't trade away anything.
Interpretation & Misconception Qs 7, 9 States that there is a 95% probability that the parameter falls in a specific interval. Recognizes the interpretation is about the method, but uses imprecise language. Identifies that p = 0.5 produces the widest possible intervals. Writes the AP-correct interpretation: "We are 95% confident that the interval captures the true proportion." Explains that for a specific computed interval, the true value is either in it (100%) or not (0%) — the 95% refers to the long-run success rate of the procedure. Connects p = 0.5 to the maximum of p(1−p).
Where to look for the misconception Question 9 is the highest-stakes question in the lab. Read student responses carefully — many will write "there is a 95% chance the true value is in this interval" even after watching the simulation. The exit ticket (next page) targets the same misconception. If a student gets Q9 wrong but the exit-ticket Q1 right, they understood the simulation late but they got there.

Exit Ticket
Three questions on the AP Stats CI essentials. Submit before leaving class.
01The Classic Trap
A student calculates a 95% confidence interval for the proportion of students who prefer a 4-day school week and gets (0.62, 0.74). The student states: "There is a 95% probability that the true proportion of students who prefer a 4-day school week is between 0.62 and 0.74." Is this interpretation correct? Explain why or why not based on what you saw in today's simulation.
02Manipulating the Margin of Error
If the student wanted a narrower interval, name two specific mathematical changes they could make to their study design or their calculations.
03The True Meaning
In your own words, what does the "95%" in a 95% confidence interval actually refer to?

Confidence Intervals · Answer Key
Teacher Reference
Exit Ticket Key
Teacher Answer Key
Expected Answers
Exit Ticket Key
What to look for in each response.
01The Classic Trap
Expected answer No, this is incorrect. (This is the most heavily tested CI concept on the AP Exam.) Once the interval is calculated, the true proportion is either in it (100% probability) or it isn't (0% probability). The 95% refers to the creation method, not a single calculated interval. A better interpretation: "We are 95% confident that the interval from 0.62 to 0.74 captures the true proportion of students who prefer a 4-day school week."
02Manipulating the Margin of Error
Expected answer Two valid changes:
  1. Decrease the confidence level (e.g., drop from 95% to 90%), which uses a smaller z* critical value.
  2. Increase the sample size (n), which decreases the standard error.
03The True Meaning
Expected answer The 95% refers to the success rate of the method. It means that if we were to take many random samples of the same size from this population and calculate a confidence interval for each one, about 95% of those intervals would successfully capture the true population proportion.

PBA Extension · Optional
Performance-Based Assessment · Extension Project
The Confidence Audit
Pick a published statistical claim — a poll, a clinical trial, a market study, a defect rate. Audit it from every angle the AI can help you with. End with a refined interpretation defensible to any AP reader.

The Driving Question

When a published study reports "95% confident," what is being claimed — and what is being assumed? Take a real claim apart, simulate it, and write the interpretation you wish the original authors had.

Student Deliverables

  • Source claim with citation (1 page). A real published proportion estimate with its confidence interval. News article, peer-reviewed study, polling org, FDA filing.
  • Skeptical Auditor transcript. Students prompt Gemini to play a skeptical statistician, and prove that conditions (Random, 10%, Large Counts) are satisfied with explicit numbers from the source claim.
  • Simulation results. Students run the CI simulation (or use the Math Hub kiosk) with the source's n and p̂. Annotate the resulting plot.
  • Three real-world contexts. Students use Gemini to generate three alternative scenarios with the same numbers but different consequences. (Defect rate vs. mortality rate vs. polling.) Compare the stakes.
  • Misconception correction. Students prompt Gemini for a plain-English explanation of the original confidence interval. Predict where Gemini will get it wrong, then correct it using AP language.
  • Refined interpretation (~250 words). The student's final, AP-defensible sentence about what the original study actually showed — and what it didn't.

The Four Phases

Phase 1 · Week 1
Find & Audit
Locate a real claim. Run the Skeptical Auditor (Way #1). Document the conditions check with numbers.
Phase 2 · Week 1–2
Simulate
Replicate the study's parameters in the simulation kiosk. Capture the plot and the coverage rate.
Phase 3 · Week 2
Context
Use Way #3 to generate three different real-world contexts. Argue which interpretation matters most.
Phase 4 · Week 3
Refine
Use Way #4 and #5 to catch and correct AI's predictable misinterpretation. Write the refined claim.

The AI Move

This PBA folds all five AI integration strategies into one project. The student moves through them sequentially, learning that AI is most useful when used as a partner to interrogate — Skeptical Auditor, Simulation Coder, Context Generator, Misconception Buster, Wording Refiner — rather than as an oracle to defer to.

What excellence looks like The strongest projects don't just describe the original study — they argue that the original interpretation was either correct, slightly wrong, or seriously misleading, citing the simulation evidence. The "refined interpretation" at the end should be one sentence the student is genuinely proud of.
